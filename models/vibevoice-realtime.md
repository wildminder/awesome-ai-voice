# VibeVoice-Realtime

Real-time TTS model from Microsoft with streaming text input and ultra-low latency (~300ms).

## Links

- GitHub: https://github.com/microsoft/VibeVoice
- HuggingFace: https://huggingface.co/microsoft/VibeVoice-Realtime-0.5B

## Features

- parameters: 0.5B
- voice_cloning: yes
- asr: no
- pronunciation: yes
- emotion_control: yes
- languages: Multilingual
- streaming: yes (300ms)
- license: MIT
- max_duration: ~10 minutes
