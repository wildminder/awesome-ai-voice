# Irodori-TTS-500M-v2

Japanese Text-to-Speech model based on Rectified Flow Diffusion Transformer. Features emoji-based style and sound effect control by embedding emojis in input text for expressive speech generation.

## Links

- HuggingFace: https://huggingface.co/Aratako/Irodori-TTS-500M-v2
- GitHub: https://github.com/Aratako/Irodori-TTS
- Demo: https://huggingface.co/spaces/Aratako/Irodori-TTS-500M-v2-Demo

## Features

- parameters: 500M
- voice_cloning: yes
- asr: no
- pronunciation: no
- emotion_control: yes
- languages: Japanese
- streaming: no
- audio_output: 48kHz waveform
- license: MIT
