# Fun-CosyVoice 3.0

Advanced TTS system based on LLMs for zero-shot multilingual speech synthesis from FunAudioLLM.

## Links

- GitHub: https://github.com/FunAudioLLM/CosyVoice
- HuggingFace: https://huggingface.co/FunAudioLLM/Fun-CosyVoice3-0.5B-2512
- arXiv: https://arxiv.org/abs/2505.17589

## Features

- parameters: 0.5B
- voice_cloning: yes (Multi-lingual/Cross-lingual)
- asr: no
- pronunciation: yes (Pinyin/CMU)
- emotion_control: yes
- languages: 9 + 18+ Chinese dialects
- streaming: yes (150ms)
- license: Apache-2.0
