# KittenTTS

KittenTTS is an open-source realistic text-to-speech model designed for lightweight deployment. It is a state-of-the-art TTS model under 25MB with just 15 million parameters, running without GPU on any device.

## Links

- GitHub: https://github.com/KittenML/KittenTTS
- HuggingFace: https://huggingface.co/spaces/KittenML/KittenTTS-Demo

## Features

- parameters: 15M-80M
- voice_cloning: yes
- asr: no
- pronunciation: no
- emotion_control: yes
- languages: English, Multiple
- streaming: yes
- license: Apache-2.0
