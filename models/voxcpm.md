# VoxCPM

Tokenizer-free TTS system for context-aware speech generation and true-to-life voice cloning.

## Links

- GitHub: https://github.com/OpenBMB/VoxCPM
- HuggingFace: https://huggingface.co/openbmb/VoxCPM-0.5B
- arXiv: https://arxiv.org/abs/2509.24650

## Features

- parameters: 640M-800M
- voice_cloning: yes
- asr: no
- pronunciation: yes
- emotion_control: yes
- languages: Chinese, English
- streaming: yes (RTF 0.17)
- license: Apache-2.0
