# Fish Speech

State-of-the-art open source TTS and voice cloning model that generates natural, realistic, and emotionally rich speech.

## Links

- GitHub: https://github.com/fishaudio/fish-speech
- Website: https://fish.audio/

## Features

- parameters: 4B (S1), 0.5B (S1-mini)
- voice_cloning: yes
- asr: no
- pronunciation: yes
- emotion_control: yes
- languages: 8 (EN, JP, KO, ZH, FR, DE, AR, ES)
- streaming: yes
- license: Apache-2.0
- rtf: ~1:7
