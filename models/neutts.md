# NeuTTS

NeuTTS is a collection of open-source on-device TTS models with instant voice cloning. Built off LLM backbones with GGUF format quantizations for efficient on-device deployment.

## Links

- GitHub: https://github.com/neuphonic/neutts
- HuggingFace: https://huggingface.co/neuphonic/neutts-air
- HuggingFace: https://huggingface.co/neuphonic/neutts-nano

## Features

- parameters: 360M (Air), 120M (Nano)
- voice_cloning: yes (3-second)
- asr: no
- pronunciation: no
- emotion_control: no
- languages: English, Spanish, German, French
- streaming: yes
- license: Apache-2.0 (Air), NeuTTS Open License 1.0 (Nano)
- on-device: yes (GGUF quantizations)
